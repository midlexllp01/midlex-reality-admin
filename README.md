## 🚀 Vercel Deployment Guide

To deploy this admin portal to **`midlex-reality-admin.vercel.app`**:

1. In [Vercel](https://vercel.com/new), import repository **`midlexllp01/midlex-reality-admin`** (or import `midlexllp01/midlex-realty` and set Root Directory to `admin`).
2. Set **Project Name**: `midlex-reality-admin`.
3. Set Environment Variables:
   - `NEXT_PUBLIC_API_URL`: `https://midlex-reality.onrender.com`
   - `NEXT_PUBLIC_SITE_URL`: `https://midlex-reality-admin.vercel.app`
   - `NEXT_PUBLIC_MARKETPLACE_URL`: `https://midlex-reality.vercel.app`
4. Click **Deploy**.
5. In **Project Settings** > **Domains**, verify the domain is set to `midlex-reality-admin.vercel.app`.

## ✨ Features
- Secure JWT authentication with session persistence.
- Manage property catalogue (Create, Edit, Delete).
- Media Studio: upload images & video tours via web links (YouTube, Vimeo, MP4) or direct device file uploads.
- Cover photo management with one-click reordering.
- Real-time customer inspection requests and inquiries tracking.
- Direct links to preview listings on the live marketplace (`https://midlex-reality.vercel.app`).
